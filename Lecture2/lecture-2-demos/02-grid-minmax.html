Demo 02 — display: grid + minmax()

Resize the window slowly. Watch what each grid does.

1. Fixed: three equal columns at every size

grid-template-columns: repeat(3, 1fr); — rigid; cards squish on phones.

2. auto-fill + minmax(200px, 1fr)

Pack as many 200-px-min columns as fit; each can grow to 1fr. Responsive without media queries.

3. auto-fit (cards stretch to fill the row)

Same as above, but with only a few items, the existing cards stretch to fill — handy or distracting depending on your design.

4. Page layout with grid-template-areas

Named areas keep the source order readable while letting the visual layout differ.
