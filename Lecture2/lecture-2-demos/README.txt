Lecture 2 — Runnable Demos
===========================

Each file is self-contained (HTML + inline CSS). Just open in a browser.

  01-position.html       static, relative, absolute, fixed, sticky
  02-grid-minmax.html    display: grid + minmax + auto-fill / auto-fit
  03-flex.html           display: flex — five common patterns
  04-keyframes.html      @keyframes (fade-in, pulse, shimmer)
  05-media-queries.html  min-width, print, prefers-reduced-motion,
                         prefers-color-scheme — all on one page

Use them as live talking points during the lecture, then point students
back to them while they work in lecture-2-starter/.
