Demo 05 — Media queries

One page, four media query types: mobile-first min-width, print, prefers-reduced-motion, and prefers-color-scheme.

Try each test:

  • Resize the window from very narrow to wide — gallery goes 1→2→3 columns.
  • Press Cmd/Ctrl+P — sticky stuff is gone, link URLs print inline.
  • Toggle "Reduce motion" in your OS, reload — the fade-in stops.
  • Toggle dark mode in your OS — the palette flips with no JS.
